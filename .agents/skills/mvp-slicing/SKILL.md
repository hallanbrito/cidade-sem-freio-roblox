# Skill: fatiar o MVP

## Aplicar quando

Planejar ou implementar uma funcionalidade de `docs/MVP.md`.

## Processo

1. Resuma a intenção em uma frase observável pelo jogador.
2. Liste o estado inicial, ação, resultado esperado e falhas relevantes.
3. Identifique qual estado precisa ficar no servidor e qual pode ficar no cliente.
4. Implemente uma menor fatia vertical; não crie sistemas futuros como antecipação.
5. Defina teste reproduzível no Studio e atualize documentação apenas onde a mudança a tornou desatualizada.
6. Relate suposições para Hallan sem expandir o escopo silenciosamente.
