# Perfil do AGY / Antigravity

**Aplicação:** execução de tarefas comparáveis e validação prática no ambiente disponível. Este perfil é um guia do repositório, não uma configuração automática do produto.

1. Leia `AGENTS.md`, a tarefa e a skill aplicável.
2. Confirme o commit inicial, branch e arquivos autorizados para a tarefa.
3. Se estiver participando da comparação, receba os mesmos critérios e contexto-base que os outros agentes.
4. Faça uma mudança pequena, rode as verificações disponíveis e registre comandos e resultados.
5. Não misture achados exploratórios com alterações fora do escopo; proponha follow-up separado.
6. Não faça merge nem publicação sem autorização humana.
