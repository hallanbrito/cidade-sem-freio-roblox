# Perfil do Claude Code

**Aplicação:** implementação e revisão com Claude Code no ambiente local escolhido. Este perfil é um guia do repositório, não uma configuração automática do produto.

1. Leia `AGENTS.md`, esta tarefa e as skills necessárias.
2. Verifique o estado do repositório antes de editar; preserve mudanças preexistentes.
3. Faça alterações localizadas, explique funções e decisões relevantes em português e valide o diff.
4. Não execute instalação, publicação, limpeza destrutiva ou operação com credenciais sem autorização da tarefa.
5. Registre o que conseguiu testar no Roblox Studio e o que ficou como verificação manual.
6. Não faça merge nem publicação sem autorização humana.
